📘 Tether Aerostat Simulation Tool Help

1. General Usage:

① Run with a maximized window to avoid UI layout issues.
② Unexpected results are usually caused by unreasonable parameter settings; please check your inputs first.
③ For further communication, contact: nzw0322@163.com.

2. Aerostat Parameters:

① Step size defaults to V^(1/3), does not affect final results but slightly impacts speed. Ensure it is greater than twice the tether segment length to avoid oscillations.
② Reference length is typically the hull length or V^(1/3) (default), can be customized for special shapes.
③ Reference area is typically the maximum cross-sectional area or V^(2/3) (default), can be customized.
④ Envelope mass is the total empty mass of the aerostat (excluding helium).
⑤ Coordinates are in the body-fixed frame, origin at the center of mass (default coincident with CG), X-axis points forward, Y-axis upward. Default buoyancy center coincides with CG.
⑥ Aerodynamic coefficients are polynomial coefficients from highest to lowest order, separated by commas.

3. Tether Parameters:

① Segment length defaults to a function of volume, can be customized. Recommend keeping segment count between 500-1000. Too small may cause visualization issues, too large may affect accuracy.
② Attachment point coordinates in body frame. Default main attachment is below CG at a distance of the maximum diameter. Note the negative sign for y.

4. Wind Field Parameters:

① Wind profile uses power law; reference speed is at reference height (typically 10 m above ground).
② Ground altitude is local altitude, default 0. If changed, adjust reference height and wind speed accordingly. Actual altitude = final altitude - ground altitude.
③ Wind shear exponent depends on terrain; smoother terrain gives smaller exponent, default 1/7. Set to 0 for uniform wind.

5. Atmospheric Parameters:

All these parameters are altitude-dependent and affect every iteration. The default ISA model is strongly recommended; modification is discouraged.

6. Additional Notes:

This HTML code originates from a MATLAB code. If issues arise, try the original MATLAB code with the same parameters to verify, then adjust accordingly.
